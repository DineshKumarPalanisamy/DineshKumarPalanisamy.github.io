PMSKnowledgeBase

A grounded RAG assistant in .NET 10 over a hotel property-management (PMS) sample dataset. Every answer cites its sources, and when the documents don't support an answer, it refuses instead of guessing.

INGEST → RETRIEVE → ANSWER WITH CITATIONS → REFUSE WHEN UNSUPPORTED

  • .NET 10
  • Microsoft.Extensions.AI
  • Qdrant
  • Azure AI Search
  • Ollama
  • 195 tests
View on GitHub →
Problem

Hotel staff need answers from manuals and policies, and a wrong answer at the front desk costs money and trust.

Approach

Retrieval over the document set, answers grounded in what was retrieved, citations on every answer, and an explicit refusal path.

Result

195 automated tests covering retrieval, citations and refusals. MIT licensed.

PASSWORDS → ENTRA ID SSO

  • OpenID Connect

Case study · Front end

Angular monolith to Nx monorepo

9 COUPLED MODULES → AFFECTED-ONLY BUILDS

  • Angular
  • Nx
  • CI/CD
Problem

9 tightly coupled modules; every change rebuilt everything.

Change

Split into an Nx monorepo that builds only affected modules.

Result

Builds 55% faster. 11 developers ship independently.

How I build with AI

Step 1

Settle every open question first

Before the AI writes code, it asks and answers every open question with me until we agree. It doesn't make design decisions on its own.

Step 2

Review every line

When the AI finishes, I review each line before it ships. I own the code, not the model.

Step 3

Write the hard parts myself

When a concept is new or hard, I write that code by hand to build my own judgment.

dk-mode is the Claude Code skill set I use for this: playbooks for bugs, features and PRs, test-first where a cheap test exists, local verification with evidence, and code review by three models.
